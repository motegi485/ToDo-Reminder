# ToDo リマインダー

オフラインでも動作する、シンプルで実用的な PWA 製 ToDo + リマインダーアプリ。
スマートフォンでもデスクトップでも同じ操作感で使え、複数端末間で同期コードによる同期、
Web Push による通知配信に対応します。

🌐 **[アプリをブラウザで開く](https://todo-reminder.pages.dev/)**

> **これは個人が趣味で運営しているアプリです。** 作者本人と身近な数人での利用を想定しており、
> 不特定多数向けのサービスではありません。利用する前に
> [データの取り扱いと利用上の注意](#データの取り扱いと利用上の注意) を必ずお読みください。

## できること

「とにかく開いてすぐ書ける、通知でちゃんと思い出す」ことを最優先に設計しています。
「TODO リスト管理」だけでなく **「忘れない仕組み」** までを 1 アプリでカバーすることが目的です。

- **ログイン不要** — ランダム生成された 12 桁の同期コードがユーザー識別子。アカウント登録の手間がない
- **オフラインファースト** — 機内モードや圏外でも操作でき、オンライン復帰時に自動同期
- **通知ファースト** — 指定した時刻に Push 通知が飛ぶ。アプリを起動していなくても OS が知らせる
- **多端末同期** — 同期コードを別端末に入力するだけでタスクが共有される
- **モバイル最適化** — iOS / Android のホーム画面に追加すればネイティブアプリのように使える

### 主な機能

| 分類 | 内容 |
|---|---|
| タスク | シンプルタスク／定量タスク（「30 ページ読む」など目標値に対する進捗を加算）／期限（表示専用）／チェックボックスの色（15 色 + 自動） |
| 繰り返し | daily / weekly / monthly。完了しても消えず、カレンダー境界を跨ぐと自動で未完了に戻る |
| リマインダー | 非繰り返しは絶対時刻、繰り返しは切り替わり 0:00 の N 分前。Web Push で配信し、未購読の端末では起動中のローカル通知にフォールバック |
| 整理 | プロジェクト単位のグルーピング（後からリネーム・統合可）／プロジェクト内のドラッグ並べ替え／5 種類の表示順設定 |
| レポート | 週間達成率・連続達成日数・過去 30 日の完了数・定量タスクの現状 |
| 表示 | ダークモード／文字サイズ 4 段階／ハプティクス／楽観的 UI 更新 |
| その他 | ソフト削除（365 日後に物理削除）／通知タップで該当タスクへスクロール |

## 技術スタック

| 領域 | 採用 |
|---|---|
| フロントエンド | React 18 / TypeScript 5 / Vite 5 / Tailwind CSS 3.4 / React Router 6 |
| ローカル DB | Dexie 4（IndexedDB） |
| UI 部品 | lucide-react（アイコン）／@dnd-kit（ドラッグ並べ替え） |
| PWA | vite-plugin-pwa（`injectManifest` 戦略） |
| バックエンド | Cloudflare Workers / D1 / Pages |
| 通知 | Web Push（@block65/webcrypto-web-push）+ Cron Triggers |

Cloudflare の**無料枠のみ**で運用しています。

## 開発

```sh
npm install
npm run dev          # http://localhost:5173
```

| コマンド | 内容 |
|---|---|
| `npm run dev` | 開発サーバー。**Service Worker は無効**なので SW / Push の確認はできない |
| `npm run typecheck` | フロント（`tsc -b`）と Workers（`tsc -p tsconfig.workers.json`）の**両方**を型チェック |
| `npm run build` | typecheck + 本番ビルド |
| `npm run preview` | ビルド成果物を配信（http://localhost:4173）。SW / Push の確認はこちら |

`.env`（git 管理外）を `.env.example` をベースに作成してください。両方未設定でもアプリは動きますが、
サーバー同期と Push 購読は無効になります。

```
VITE_API_URL=https://todo-reminder-api.<account>.workers.dev
VITE_VAPID_PUBLIC_KEY=<公開鍵>
```

**自動テスト・lint・CI はありません。** CI/CD もないため、本番反映はすべて手動です。
セットアップ・デプロイ・運用の詳細は下記の設計ドキュメントを参照してください。

## データの取り扱いと利用上の注意

利用する前に以下を理解してください。

| 項目 | 内容 |
|---|---|
| サーバーに保存されるもの | タスク本文（タイトル）、期限、リマインダー時刻、繰り返し設定、プロジェクト名、色、タイムゾーンオフセット、同期コード、Push 購読の endpoint |
| 保存先 | 作者個人の Cloudflare アカウント配下の D1。**作者は技術的にすべての内容を閲覧できます。** 見られて困ることは書かないでください |
| 第三者への送信 | Push 通知の配信時のみ、タスク名が各ブラウザベンダの Push サービス（Google / Apple / Mozilla / Microsoft）を経由します |
| 保持期間 | 削除済みと非繰り返しの完了済みは 365 日後に自動削除。未完了のタスクは削除されません |
| 削除の依頼 | **アプリ内に「サーバー上のデータを消す」機能はありません。** 作者に同期コードを伝えて手動削除を依頼してください |
| コードの紛失 | 同期コードが唯一の識別子です。**紛失するとサーバー上のデータには二度とアクセスできず、復旧手段もありません。** 控えを取ってください |
| 可用性・保証 | 無料枠で動いており、**無保証**です。予告なく停止・データ消失する可能性があります。障害時の告知手段もありません |
| バックアップ | 作者が手動でエクスポートする場合、そのファイルには利用者全員のタスク本文が平文で含まれます |

同期コードは他人に知られないよう扱ってください。コードを知る相手は、そのコード配下のタスクをすべて
読み書きでき、通知に任意の文字列を表示させることもできます。
**漏洩した場合でもコードを失効させる機能は現時点でありません**（新しいコードへの切替はできますが、
旧コード配下に残る削除済みタスクは最長 365 日残ります）。

なお、API を利用できる同期コードは Worker 側の許可リスト（`ALLOWED_SYNC_CODES`）で制限しています。
リストに無いコードからのアクセスはすべて拒否されます。
